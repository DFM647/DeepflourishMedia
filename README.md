# Deepflourish Media Website

Static multi-page website for Deepflourish Media, partnered with Breccan Jorvik Company.

## Pages
- `index.html` — Home
- `services.html` — Services
- `verification.html` — Verification & Proof
- `about.html` — About & Contact

## Deploy with GitHub Pages
1. Create a new GitHub repository.
2. Upload **everything inside this folder** to the repository root.
3. Make sure `index.html` is at the repository root.
4. In GitHub, open **Settings → Pages**.
5. Under the build/deployment source, choose **Deploy from a branch**.
6. Select the branch containing these files (usually `main`) and the `/ (root)` folder.
7. Save. GitHub will provide the published site address.

No build command or framework is required. The site uses HTML, CSS and vanilla JavaScript, so it can be published directly as a static GitHub Pages site.

## Notes
- The contact form uses a `mailto:` action and opens the visitor's email application; it does not store submissions.
- Replace any social links you later want to change directly in the HTML.
- Keep the `assets` folder in the same location relative to the HTML files.
